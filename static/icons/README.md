# Icon attribution

The inline SVG path data in `index.html` for the PDF file, GitHub, copy, and chevron-up icons comes from [Font Awesome Free 5.15.1](https://github.com/FortAwesome/Font-Awesome/releases/tag/5.15.1) by Fonticons, Inc.

The icons are licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). See the upstream terms at <https://fontawesome.com/license/free> and the pinned release license in `Font-Awesome-LICENSE.txt`.

The paths are unchanged. They were converted from Font Awesome's JavaScript-generated SVG markup to static inline SVG elements so the site does not require runtime CSS injection or the Font Awesome JavaScript payload.
